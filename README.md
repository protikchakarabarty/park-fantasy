# 🍽️ Park Fantasy

A premium restaurant website for **Park Fantasy (Jessore, Bangladesh)** built with **Next.js 16**, **React 19**, **TypeScript**, **Tailwind CSS**, **Three.js**, and **Framer Motion**.

## ✨ Features

- 🍔 Online food ordering
- 🛒 Shopping cart & checkout
- 📅 Table reservation
- 📍 Interactive map (Leaflet + OpenStreetMap)
- 🚚 Delivery zones (Jessore District)
- ⭐ Customer reviews
- 🎥 Live kitchen videos
- 📱 Fully responsive
- 🌙 Dark mode
- ⚡ Performance optimized
- 🔍 SEO optimized
- 👨‍💼 Admin dashboard

## 🛠 Tech Stack

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS
- Three.js
- Framer Motion
- Leaflet
- Lucide React

## 🚀 Getting Started

```bash
npm install
npm run dev
```

Open:

```
http://localhost:3000
```
